# API de Gerenciamento de Projetos e Tarefas

Esta é uma API RESTful desenvolvida em Node.js, Express e MongoDB (utilizando o MongoDB Atlas) para o gerenciamento de projetos e suas respectivas tarefas. O projeto foi estruturado seguindo o padrão MVC (Model-View-Controller), com separação de rotas, controllers, models e configuração do banco.

## Tecnologias Utilizadas

*   **Node.js**
*   **Express**
*   **MongoDB** (via MongoDB Atlas)
*   **Mongoose**
*   **Dotenv** (para variáveis de ambiente)

## Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:
*   [Node.js](https://nodejs.org/en/) (versão 18 ou superior)
*   Uma conta no [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) (para o banco de dados na nuvem)
